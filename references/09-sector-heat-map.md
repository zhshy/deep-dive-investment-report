# 板块冷热地图：把指数结论落到"钱在哪"

指数结论回答**要不要配**，板块结论回答**配哪个**。只给前者，读者只能买宽基；给了后者，才谈得上"买对结构"。

本文件是七层结构之外的**可选第八个视角**。触发条件很简单：读者会问"那买什么板块？"

## 一、为什么指数结论不能直接推板块

一个反例：

> "创业板指 PE 26.96 倍、近十年 4.9% 分位"——这句话是对的，但它内部的分布可能是：
> 光模块处 5% 分位（真便宜）、半导体处 85 倍绝对估值（从泡沫回落）、电池处 20% 分位（中性）。
> **同一个"4.9% 分位"里，装着三种完全不同的处境。**

指数是**加权平均**，板块是**分组**。加权会抹平分布，而决策恰恰发生在分布里。

**推论**：凡报告给出"指数极值低估"，必须追问一句"这个分位数在板块之间是怎么分布的"。答不出来，这个分位数就不能用来指路。

## 二、象限的轴怎么选（这一步决定整张图有没有信息）

| 轴 | 变量 | 性质 | 数据频率 |
|---|---|---|---|
| 横轴 | **估值分位** | 存量位置，连续、可比 | 日频（分位需长窗口） |
| 纵轴 | **资金方向**（流入/流出） | 流量，只有方向稳健 | 单日/月度/季度 |

**为什么不能反过来**：资金流的数据噪音极大，且不同期间（单日主力、季度北向、月度两融）量纲完全不同——它只能提供"方向"，不能提供"位置"。把资金放横轴，等于用最不可靠的变量定义刻度。

**两条硬规则**：

1. **资金口径必须在图注里写死期间**（"Q3 北向持仓变动" / "11-03 单日主力净流入"）。不同期间的流数据**禁止画在同一张图上**——那是把季度趋势和单日噪音并排比较。
2. **估值分位必须统一窗口**（近十年 / 2008 以来）。混窗口会让"高位"和"低位"互换。

## 三、四格读法：空格本身就是结论

| | 便宜（分位低） | 贵（分位高） |
|---|---|---|
| **资金在进** | ① 真便宜且在买 —— 唯一可加仓的格 | ② 看起来便宜、实际不便宜 |
| **资金在撤** | ③ 冷但便宜 —— 赔率所在 | ④ 跌了但不便宜 —— 陷阱所在 |

| 格 | 含义 | 操作含义 |
|---|---|---|
| ① | 有增量共识 | 可直接进入候选池，但要查"为什么还没涨" |
| ② | 拥挤的防御 | 买它的理由只能是"股息 > 国债"，不能是"便宜" |
| ③ | 无人问津的便宜 | **候选池的真正来源**：等一个触发条件即可 |
| ④ | 泡沫释放中 | 不能用"跌幅"作为买入依据，必须看绝对倍数 |

**空格怎么读（本方法最有信息量的一步）**：

- **① 空** → 没有增量共识，市场在做防御性停留。**这不是风格切换，是"没有好去处"**；风格切换的前提是那边便宜，现在那边不便宜，所以这轮防御有期限。
- **② 空** → 资金连防御都不愿意做，全面撤离。此时任何板块都不该加。
- **③ 空** → 便宜的已经没人卖了（筹码出清完成），是底部特征而非风险特征。
- **④ 空** → 泡沫已出清干净，市场进入"只有便宜没有贵"的状态，通常对应极端底部。

> **写法模板**：不要说"当前板块分化"，要说"① 是空的，② 挤着 X 和 Y，这说明……"。**用空格说话，比用形容词说话有力。**

## 四、"冷门"有两个意思，混用就会买错

这是本方法最容易犯的错，也是最值得在报告里显式拆开的一处。

| | 资金冷（在流出） | 资金不冷 |
|---|---|---|
| **估值冷（分位低）** | 真·冷门：跌幅与估值同时到位 → **唯一有赔率的一格** | 低估但被忽视，需查是否有基本面瑕疵 |
| **估值不冷（分位高）** | 假·冷门：跌得多但依然贵 → **最危险的误判** | 热门且贵 → 拥挤 |

**一句话规则**：

> **资金冷是现象，估值冷是资格。** 只有估值冷才进入候选池；资金冷只是"为什么现在能以便宜价买到"的解释。

典型误判：科创50 跌 **49.0%** 之后 PE 仍 **85.75 倍**——它同时是"跌得最狠"和"最不便宜"。把"跌了 49%"当作买入理由，等于用跌幅代替估值（见 `01-caliber-and-valuation.md` §五.2）。

## 五、热点：判别"资金再配置"还是"盈利改善"

同样是涨，驱动不同，持有期限和退出条件完全不同。

| 判别 | 盈利驱动 | 资金再配置驱动 |
|---|---|---|
| ① 盈利预期是否同期上修 | 上修 | **未上修** |
| ② 是否同类资产同步上涨 | 不一定 | **是**（相对价值重估） |
| ③ 该板块自身分位 | 中低位启动 | 往往**已在高位** |

三条里若 ②③ 成立、① 不成立，就是**再配置**——它的本质是"别处更差"，不是"这里更好"。

**必须写出的自带退出条件**：

```
若上涨理由是"股息率 3.0%–3.4% > 10Y 国债 1.634%"
→ 退出条件 = 股息率被买到贴近国债，利差消失
```

这比写"注意回调风险"有用得多，因为**它是可观测、可触发的**。凡热点，都要能写出这么一行公式；写不出，说明它的上涨理由还没被想清楚。

## 六、龙头点评：只问一句"分母变了还是倍数变了"

| 类型 | 特征 | 跌幅的含义 | 操作含义 |
|---|---|---|---|
| **A · 业绩在、估值被重定价** | 净利仍高增（如 Q3 +42.9%），PE 从 40–55 倍压到 20–27 倍 | 倍数切换，不是盈利崩塌 | 等**现金流**验证（C2 类条件），**不等反弹** |
| **B · 估值靠叙事** | PE 极高、无现金流锚（如所属指数仍 85 倍） | 泡沫释放 | 底部由情绪决定，**不进点位框架** |
| **C · 资金再配置型防御** | 逆势上涨、北向加仓 | 上涨=配置行为，非盈利改善 | 天花板=股息-国债利差，利差消失即退出 |

**判别只需一问**：

> **这个跌幅，是分母（盈利）变了，还是倍数（估值）变了？**

- 分母变了 → 逻辑杀，任何反弹都是逃命（见 `02`）。
- 倍数变了 → 估值杀，跌到位就有价值。
- **两类龙头的抄底逻辑不同，绝不能用同一套话术**。A 类跌 65% 仍然可能是好资产，B 类跌 70% 仍然可能很贵。

**二线不要当"更便宜"**：同一产业链上的二线弹性更大——跌得快、反弹也快，但它不具备独立逻辑。用"二线跌得更多"证明"二线更便宜"，是把 β 当成 α。

## 七、数据与披露

| 指标 | 频率 | 能回答 | 不能回答 |
|---|---|---|---|
| 主力资金净流入 | 单日 | 当天谁在被卖 | 趋势（噪音过大） |
| 北向持仓变动 | 季度 | 结构性再配置方向 | 短期节奏（滞后） |
| 两融行业余额 | 月度 | 杠杆去向（申万一级） | 个股卖压（见 `04` §四之二） |
| 指数行业权重 | 季度 | 指数波动的归因 | 未来收益 |

**必披露三句**：① 每个流数据标注期间；② 行业分类口径（申万一级 / 二级）；③ 是否同源（不同数据商的"主力净流入"定义不同，不可混算）。

**禁止**：把"季度北向 −2,844 亿"和"单日主力 −186 亿"放进同一句话做加总或倍数比较。要么统一期间，要么分别陈述并说明不可比。

## 八、四个退化模式

1. **以跌幅代便宜**：跌 49% 后仍 85 倍，是"跌了但不便宜"。
2. **把"冷门"当一个词用**：资金冷与估值冷混为一谈，会在泡沫里抄底。
3. **把资金流入当看好**：ETF 逆势买入是被动机制，两融下降是结果不是原因（见 `04` 与 `SKILL.md` Phase 6）。
4. **只有象限没有名字**：画了 2×2 却填不出具体板块/标的——说明这是排版，不是研究。

## 九、摘要页规格（五块，一页讲完）

当读者要的不是全文而是结论时，按这五块组织，顺序不可颠倒：

| # | 模块 | 要求 |
|---|---|---|
| 1 | **核心结论** | 三句话 + 4 个 KPI；每句必须带数字，禁止"震荡分化"类表述 |
| 2 | **板块冷热地图** | 2×2 象限，四格填名，空格要显式标注并解释 |
| 3 | **热点 / 冷门** | 各一段 + 依据表（板块 / 状态 / 数据证据 / 性质判定） |
| 4 | **龙头点评** | 按 A/B/C 三类分组，每类给"该等什么、不该等什么" |
| 5 | **短期 / 长期方向** | 两套时间尺度分开写：短期只回答"动不动手"，长期只回答"买什么、买多少" |

**摘要页的三条纪律**：

1. **前置**。核心结论必须在第一屏，读者不滚动就能拿到判断。
2. **不复述**。摘要页是"结论 + 依据指针"，不是全文的压缩版；细节一律指回正文章节。
3. **短期与长期禁止混写**。"短期不加仓"和"长期配 9%"可以同时成立，混成一句就变成自相矛盾。

**短期段的写法**（只写动作，不写理由堆砌）：
> 不加仓（条件只满足 1/5）→ 只盯两融（第一个作用在卖压端的政策）→ 反弹到 MA20 是换仓窗口不是加仓窗口 → 不抄底龙头（估值体系切换期胜率低）→ 已有仓位不动（三折扣算出来的，不是保守）。

**长期段的写法**（只写结构与刻度）：
> 双轨结构（底仓 + 弹性仓）→ 主线换为"现金流转化验证者"→ 防御端的角色是压波动不是赚超额 → 最大风险是"便宜凭空消失"（亏损面扩张会抬升 PE）→ 到点不看条件 = 不动手。
