# 口径体系与估值坐标

## 一、为什么口径是第一性问题

同一个 PE 分位可以同时是 2.99%、4.09%、5.68%——这不是数据错误，而是三个不同口径。如果报告里只写"PE 处历史 3% 分位"而不说样本起点，读者无法复核，也无法判断这个数字在什么条件下会变。

**正确陈述格式**（缺一不可）：

> PE(TTM) 26.91 倍，处上市以来（起算日 2010-06-01，N=3,985 个交易日，整体法）**2.99%** 分位；处近十年（N=2,429）**4.90%** 分位。

## 二、五个口径维度

| 维度 | 取值 | 影响方向 |
|---|---|---|
| 样本起点 | 上市以来 / 近 10 年 / 近 5 年 | 起点越早，含高估值年代越多，当前分位越低 |
| 采样频率 | 日 / 周 / 月 | 频率越低，极值越被平滑 |
| 盈利口径 | TTM / 自然年度 / 一致预期 | TTM 平滑，自然年度锚定当期，差异可达 40pct |
| 加权方法 | 整体法 / 中位数 / 等权 | 整体法被大市值主导，中位数抗极端值 |
| 会计口径 | 含/不含融资租赁、归母/扣非 | 影响现金流与利润的可比性 |

**规则**：同一指标出现两个以上口径时，全部并列给出，并解释差异来源。禁止"取一个更好看的"。

## 三、分位之外必须做的四件事

### 1. 极值参照点

给历史最低 PE/PB 及其**当日点位与日期**，算出距离：

```
距极值空间 = 当前值 / 历史最低值 − 1
```

示例：PE 26.91 距历史最低 22.88（2024-02-02，收盘 1,550.37）还有 **15.0%** 空间；PB 3.82 距历史最低 2.507（2012-12-03，收盘 593.66）还有 **34.4%** 空间。

**诊断价值**：两个空间的**不对称**本身是信号。PE 空间显著小于 PB 空间 → 说明 PE 的分母（盈利）可能被高估——如果利润真实且可持续，PE 不该比 PB 更接近底部。这个反证比任何分位数字都硬。

### 2. PE-PB-ROE 三角

由 `PE = PB / ROE` 反推隐含 ROE：

```
隐含 ROE = PB / PE
当前：3.82 / 26.91 ≈ 14.2%
历史中位隐含：4.94 / 47.18 ≈ 10.5%
```

**判读**：当前隐含 ROE 高于历史中位 → PB 分位偏低源于**净资产扩张快于股价**，而非盈利能力恶化。这解释了"PE 第 3 分位 + PB 第 20 分位"的分化不应被读成"利润质量有问题"。

### 3. 股权风险溢价 ERP

```
ERP = 盈利收益率 − 10Y 国债收益率 = 1/PE − y10
例：1/26.9076 − 1.6386% = 3.72% − 1.64% = 2.08%
```

**陷阱**：低利率环境下 ERP 会被动压缩，即使 PE 不高，权益相对债券的补偿也很薄。必须与股息率交叉验证：

```
股息率 1.31% vs 10Y 国债 1.64%  →  低 0.33pct  →  股息替代债券的防御逻辑不成立
（对照：沪深300 股息率 3.04%，高出国债 1.41pct）
```

结论句形态："单纯从股息替代债券的防御视角，该标的**不具备**配置价值，其投资逻辑必须依赖成长而非股息。"

### 4. 比价与横截面

- **比价**：PE(A)/PE(B) 的比值及其历史分位排名，写成 `x/N` 形式。
  > PE 比值 2.09 倍（26.9076/12.8654），处近十年第 0.25 百分位，排名 7/2,427——即近十年 99.75% 的时间里，A 相对 B 的估值溢价都高于当前。
- **横截面表**（3–4 个同类标的）：点位 / PE / PB / PE 分位 / PB 分位 / 年内涨跌 / 最大回撤。

横截面的标准用途是揭示**错位**：
> 回撤最深的（−47.42%）估值分位仍在 66.91%（从泡沫回落，跌幅没转化为便宜）；跌幅最浅的（−28.09%）估值分位 1.73%（最便宜且跌最多）。
> 实践含义：**以"跌了多少"作为买入依据是危险的，应以"跌到什么估值"为锚。**

## 四、三个参照系与"三张便宜的脸"

必须同时给：

| 参照系 | 指标 | 回答的问题 |
|---|---|---|
| 自身历史 | PE/PB 分位 | 相对自己的过去便宜吗 |
| 无风险利率 | ERP、股息-国债 | 相对债券便宜吗 |
| 同类资产 | 比价及其分位 | 相对同类便宜吗 |

三者不必然同向。若出现"相对自身极度便宜 / 相对债券并不便宜 / 相对同类极度便宜"，**必须把这个三角矛盾写成章末张力**，并明确指出：三个"便宜"都不回答同一个问题——分母（盈利）是否可靠。

## 五、六个常见误用

1. **混用分位**：把 2.99% 与 4.90% 当同一结论的不同精度。
2. **以跌幅代估值**：跌得多 ≠ 便宜。
3. **单看 PE 或单看 PB**：两者的空间不对称才是诊断点（见 §三.1）。
4. **低利率下的 ERP 幻觉**：把 2% 的 ERP 当作安全垫。
5. **把相对便宜当绝对安全**：相对便宜可以持续很久，也可以绝对下跌（2021–22 新能源：PE 57.62 永久降至 21.42，盈利后来翻倍，指数至今仍低于当时高点约 28%）。
6. **忽略估值中枢永久下移**：均值回归不是物理定律。
