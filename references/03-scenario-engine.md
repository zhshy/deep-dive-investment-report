# 情景引擎：从二元判断到收益分布

判别给出的结论是"便宜但逻辑未验证"。这个结论**无法直接转化为操作**，因为它没回答"验证了会到哪、没验证会到哪"。情景推演的作用是把二元判断展开为连续的收益分布，让概率与赔率同时可见。

## 一、情景参数设计

以**主驱动变量**为轴（不是以价格区间为轴）。参数须含：名称、触发条件、标的盈利增速区间、主观概率、关键产业参数。

| 情景 | 命名 | 触发参数 | 标的净利增速 | 概率 |
|---|---|---|---:|---:|
| A | 加速 | 2027 capex > 1.2 万亿美元，云厂 FCF 转正，年降收窄至 −5% 内 | +18.7% ~ +25.3% | 35% |
| B | 高位维持 | capex 1.1–1.2 万亿，FCF 仍负但不再恶化 | +10.4% ~ +17.1% | 45% |
| C | 明显放缓 | capex 指引下修 > 10%，年降扩大至 −15% 以上 | −0.9% ~ +8.2% | 20% |

规则：概率之和 = 100%；概率必须声明为主观概率；**基准情景（B）概率最高但不必然过半**。

## 二、点位映射

```
P_target = P_now × (1 + g) × (PE_target / PE_now)
```

| 情景 | 概率 | 净利增速 | 悲观 | 中枢 | 乐观 | 中枢相对当前 | 中枢隐含 PE |
|---|---:|---:|---:|---:|---:|---:|---:|
| A | 35% | +18.7%~+25.3% | 4,028 | **4,403** | 4,791 | +82.4% | ~39 倍 |
| B | 45% | +10.4%~+17.1% | 2,298 | **2,703** | 2,997 | +12.0% | ~26 倍 |
| C | 20% | −0.9%~+8.2% | 1,511 | **1,905** | 2,253 | −21.1% | ~20 倍 |

## 三、期望与赔率

```
期望点位 = Σ p_i × S_i = 0.35×4,403 + 0.45×2,703 + 0.20×1,905 = 3,138.40  （+30.0%）
```

**赔率必须给两个口径**：

```
中枢口径：(S_A − P) / (P − S_C) = (4,403 − 2,413.63) / (2,413.63 − 1,905) = 3.9 : 1
尾部口径：(S_A乐观 − P) / (P − S_C悲观) = (4,791 − 2,413.63) / (2,413.63 − 1,511) = 2.63 : 1
```

**差异说明必须写**：中枢口径回答"期望的上下空间比"，尾部口径回答"极端情形的盈亏比"。前者好看、后者诚实——C 的悲观 1,511 点对应 −37.6%，这个幅度超过已实现跌幅之半，是不能忽视的尾部。

## 四、乐观情景必须自我拆解

拿到 +82.4% 不能直接报喜，要拆开：

```
中枢 4,403、增速取中值 22%、PE 26.91 → 39 倍
→ 估值修复贡献 ≈ 66.9%，盈利增长贡献 ≈ 33.1%
```

**结论句**：A 情景能否兑现，一半以上取决于市场是否愿意把估值倍数从 26.91 重新给到 39 倍——而估值扩张是最不可预测的部分。

**再补一个保守版本**（这一步最能体现克制）：若市场只愿给 24 倍（低于当前，反映中枢永久下移），即使盈利增长 22%，指数也只有约 2,626 点，涨幅仅 +8.8%。

## 五、隐含预期反推（本方法论最高信噪比的一步）

把当前价格当作方程的解，反解市场在定价什么：

```
令 PE 不变：P_now × (1 + g) = P_now  →  g = 0%
```

结论：当前价格等价于"2027 年净利润零增长"的判断。

再与三情景对照：

| 情景 | 增速区间 | 与隐含 0% 的关系 |
|---|---|---|
| A | +18.7%~+25.3% | 显著高于 |
| B | +10.4%~+17.1% | 高于 |
| C | −0.9%~+8.2% | **吻合** |

**结论**：当前价格定价的是情景 C 的盈利假设，而非基准情景 B。

**由此得出不对称结构**：
> 向下的空间需要盈利真的负增长才会打开；向上的空间只需要"盈利不下滑"就能获得。若真实增速落在 B 区间，即使估值完全不扩张，指数也应到 2,664–2,826 点（+10.4%~+17.1%）。

**必须紧跟三条限定**（否则这一段会变成看多吹票）：
1. 当前 PE 对应的是 TTM 盈利，若自然年度口径更接近真实，则"零增长"这个隐含假设本身已偏乐观。
2. 估值倍数维持不变在历史上很少成立——盈利零增长时估值往往继续压缩。
3. 未计股息与回购，股息率仅 1.31%，对总回报贡献有限。

## 六、敏感性矩阵

5×5，行 = 盈利增速，列 = 届时 PE，单元格 = 点位（相对当前涨跌幅）。**对角线锚定当前价格**（增速 0% × 当前 PE = 当前点位），这是设计锚点也是校验。

| 增速 \ PE | 20 倍 | 24 倍 | 26.91 倍 | 32 倍 | 39 倍 |
|---|---:|---:|---:|---:|---:|
| −20% | 1,435 (−40.5%) | 1,722 (−28.7%) | 1,930 (−20.0%) | 2,296 (−4.9%) | 2,798 (+15.9%) |
| −10% | 1,614 (−33.1%) | 1,937 (−19.7%) | 2,172 (−10.0%) | 2,583 (+7.0%) | 3,148 (+30.4%) |
| 0% | 1,793 (−25.7%) | 2,152 (−10.8%) | **2,413.63 (0%)** | 2,870 (+18.9%) | 3,498 (+44.9%) |
| +12% | 2,008 (−16.8%) | 2,410 (−0.2%) | 2,703 (+12.0%) | 3,214 (+33.2%) | 3,917 (+62.3%) |
| +22% | 2,188 (−9.3%) | 2,626 (+8.8%) | 2,945 (+22.0%) | 3,502 (+45.1%) | 4,403 (+82.4%) |

**必须从矩阵读出三点**（不是把表贴完就结束）：
1. 即使盈利下滑 20%，若估值回到 32 倍，指数仅跌 4.9% → 当前价格的缓冲来自估值已压缩充分。
2. 盈利 −20% 且估值压至 20 倍 → 跌 40.5% 至 1,435 点，比情景 C 的悲观值还低 → **这才是真正的尾部风险**。
3. 盈利 +22% 且估值维持 → +22%，是"不上不下"情形下的合理回报。

## 七、三个脆弱假设

逐个说明"被打破会怎样"，并排优先级：

| 假设 | 脆弱性来源 | 被打破的后果 |
|---|---|---|
| 2027 capex 增速 +20%~+30% | 依赖**外部公司**决策（非标的自身上市公司），且对方尚未给正式指引 | 区间下限守不住，C 情景概率从 20% 显著上升 |
| 盈利预期上修方向不反转 | 结构由单一个股独撑 | 该股订单表述一转，上修结构立即崩塌 → 这是最需要监控的单点 |
| 估值倍数不永久下移 | 有反例（新能源 PE 57.62 永久降至 21.42） | 即使盈利 +12%，PE 降至 20 也会跌 16.8% |

## 八、领跑指标（把情景接到操作上）

情景推演的价值**不在预测点位**，而在提供"用可观测指标判断情景、而非等点位走出来再反应"的机制。每个情景给 3–5 条：

- **A 的领跑**：上修范围扩大且不依赖单一个股 / 下游年降收窄至 ≤5% / 云厂 FCF 转正
- **B 的领跑**：现金流不再恶化也不改善 / 上调下调家数持平
- **C 的领跑**：2027E 连续两月下修且龙头开始下修 / capex 指引下修 / 存货增速继续走高 / 订单能见度表述松动
