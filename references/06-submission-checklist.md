# 提交前自检清单（57 项）

逐项打勾。任何一项不通过，回到对应 Phase 修补后再提交。

## A. 立题与口径（8 项）

- [ ] 1. 研究命题已改写成可证伪形式（不是"该不该买"）
- [ ] 2. 基准数据日、收盘值、标的代码、执行工具、对照标的均已写明
- [ ] 3. 每个估值数字都带口径（起点/样本量/加权法/盈利口径）
- [ ] 4. 同一指标的多个口径并列给出，且解释了差异来源
- [ ] 5. 未出现"择优取用"（只报好看的那个分位）
- [ ] 6. 分位陈述含 N（样本量）
- [ ] 7. 历史极值给了日期与对应点位
- [ ] 8. 所有派生数字给到可复算的分子分母

## B. 估值坐标（6 项）

- [ ] 9. 三个参照系齐备（自身历史 / 无风险利率 / 同类比价）
- [ ] 10. ERP 与股息率-国债两条都算了
- [ ] 11. PE-PB-ROE 三角反推做了，隐含 ROE 已与历史中位对比
- [ ] 12. 横截面表含 3–4 个同类标的，且指出了错位
- [ ] 13. PE 与 PB 距极值的空间已对比，不对称性被解读
- [ ] 14. 章末留下了指向下一章的张力

## C. 归因分解（6 项）

- [ ] 15. 用对数分解，不用简单百分比相加
- [ ] 16. 分解表含"占总变动比重"，且之和 = 100%
- [ ] 17. 已给至少一个独立口径（TTM vs 自然年度 等）做对照
- [ ] 18. 口径背离被解释成经济含义，而非数据错误
- [ ] 19. 若存在结论相反的算法，已并列呈现并说明各自适用场景
- [ ] 20. 已明确判定"已实现层是估值杀 / 逻辑杀 / 混合"

## D. 传导链（5 项）

- [ ] 21. 需求源头给了同比**和**环比
- [ ] 22. 现金流/融资行为的转折点已识别，并写成"定价逻辑切换"
- [ ] 23. 权重股逐一体检表含 经营现金流/净利 与 存货同比
- [ ] 24. 至少一个正面对照样本（健康公司）
- [ ] 25. 有独立的"叙事纠偏"小节

## E. 判别（10 项）

- [ ] 26. 判据分已实现层/前瞻层两组，前瞻层权重 ≥ 70%
- [ ] 27. 权重合计 100%，单一判据 ≤ 20%
- [ ] 28. 加权总分归一化后，说明了"是强度不是概率"
- [ ] 29. 风险归属分解已算占比，找出了 60%+ 的那一项
- [ ] 30. 剔除测试做了（去掉最大失分项后是否接近零）
- [ ] 31. **表格"合计"行能由列内数值逐项加出来**（用 `scripts/calc.py score` 复算，不得手工改合计）
- [ ] 32. **双层得分未混用两套尺度**（原始权重加总 与 层内归一化 不可相加）
- [ ] 33. 风险归属占比与判据权重出自同一套算术
- [ ] 34. 历史案例 ≥ 3 例，每例只提一条教训，且承认结论分裂
- [ ] 35. 三个分歧点均明确表态（是/否/部分成立），无骑墙

## F. 情景与赔率（7 项）

- [ ] 36. 三情景概率和 = 100%，且声明为主观概率
- [ ] 37. 点位映射含 悲观/中枢/乐观 + 隐含 PE
- [ ] 38. 赔率给了两个口径（中枢 / 尾部）并解释差异
- [ ] 39. 乐观情景做了内部拆解（估值贡献 vs 盈利贡献）
- [ ] 40. 做了隐含预期反推，并指出价格在定价哪个情景
- [ ] 41. 敏感性矩阵对角线锚定当前价格（自校验通过）
- [ ] 42. 三个脆弱假设已列，且排了优先级

## G. 节奏（3 项）

- [ ] 43. 三层底（估值/价格/时间）分别给结论与证据
- [ ] 44. 技术指标含"背离是否失效"的判断
- [ ] 45. 历史破位统计给了样本量、中位值、本轮已过时间，并声明局限

## H. 执行框架（8 项）

- [ ] 46. 先直接回答了 Phase 0 的命题，3 条理由排序
- [ ] 47. 逻辑条件 4–5 条，均含可观测阈值 + 当前状态
- [ ] 48. 每个非天然阈值给了来源，未校准的明确标注
- [ ] 49. 目标仓位由风险预算推导（相关系数/波动率/等效仓位）
- [ ] 50. 有合计仓位的硬上限，且优先于其他条件
- [ ] 51. 触发公式统一，且给了当前时点的代入计算
- [ ] 52. 未使用固定百分比止损；失效条件分 暂停/减仓/清仓 三层，每条写明确切仓位去向
- [ ] 53. 周度监测表 + 每周动作协议（含差值阈值与越级规则）

## I. 诚实与体例（4 项）

- [ ] 54. 诚实声明具体到"哪几项未校准 / 哪几项经过检验"
- [ ] 55. 全篇数字带来源标注 `[分位]/[统计]/[情景]/[设计]`
- [ ] 56. 每章末有张力句，下一章开头接住
- [ ] 57. 无"中性偏多、逢低关注"类模糊结论

> 共 57 项，比标题的"40 项"更多是刻意的冗余——H 段（执行框架）最容易漏，宁可多查。
