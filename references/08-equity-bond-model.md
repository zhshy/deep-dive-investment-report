# 股债模型（ERP 通道）

把"便宜"翻译成"买点"的最常用工具。它比 PE 分位更适合回答**"现在该拿股票还是拿债券"**，但也最容易在口径上出错——**同一个交易日，不同机构能给出 +0.07σ 到 +1.02σ 的不同结论，而且每个人都算对了。**

## 一、模型结构与适用边界

```
① 盈利收益率 E/P = 1 / PE(TTM)        ← 股票的"利息"
② ERP = E/P − 10Y 国债收益率           ← 买股票相对买债券多拿的补偿
③ 对 ERP 序列求 μ 与 σ，画 μ ± 1σ / ± 2σ 通道
```

**三个优点**（相对于 PE 分位）：

| 维度 | ERP 通道 | PE 分位 |
|---|---|---|
| 输入 | 当期 TTM 盈利，**不用预测** | 当期盈利，但分位只是排序 |
| 标尺 | σ 给出"偏离多少算异常"的客观刻度 | 只知排名，不知幅度 |
| 跨资产 | 直接回答"股 vs 债" | 无法回答 |

**一个致命前提**：**分母是无风险利率。当国债利率处于历史低位时，ERP 会被动抬高——这不是股票变便宜，是债券变贵。**

量化感受：10Y 从 2.7% 降到 1.634%，**即使 PE 一动不动，ERP 也会凭空上升 1.07 个百分点**，相当于 0.9 个标准差。这在 2024–2026 年的 A 股是常态，必须显式扣掉（见 §六 陷阱一）。

## 二、参数估计：三个窗口，三个答案

**这是本模型最容易出错、也最该主动暴露的地方。** ERP 是均值回归指标，但"均值"本身在漂移——因为利率中枢在往下走。

以沪深300（2026-11-03，ERP=5.76%）为例：

| 窗口 | 均值 μ | 当前相对均值 | 隐含判断 |
|---|---:|---|---|
| 全样本（2007–2026） | 4.91% | +0.85pp | "便宜" |
| 十年滚动（2016–2026） | 5.68% | +0.08pp | "中性" |
| 五年滚动（2021–2026） | 5.76% | 0.00pp | "毫无折价" |

**规则**：

1. **至少报告两套窗口**（十年 + 五年），并说明选哪套、为什么。
2. 推荐**十年滚动**：足够长以覆盖一轮完整周期，又足够短以避免把 2007 年那种极端估值算进来。
3. **禁止只报一套就下结论**——用越长的窗口，现在的 ERP 看起来越便宜。
4. 若两套窗口给出相反方向（如"十年说偏高、五年说偏低"），**这个矛盾本身就是结论**：说明性价比在修复途中，但还没到极端。

## 三、z 值与口径归因（本模型的核心技术）

```
z = (ERP − μ) / σ
```

**当 z 落在 1.0 附近（临界点）时，必须先做口径归因，再决定要不要动手。** 做法是把差异逐项拆开：

| 选择项 | 口径 A（宽松） | 口径 B（严格） | 对 z 的影响 |
|---|---|---|---|
| PE | 12.9 → ERP 6.12% | 13.52 → ERP 5.76% | **−0.34σ** |
| 窗口均值 μ | 5.05%（反推） | 5.68%（实测） | **−0.60σ** |
| 标准差 σ | 1.05% | 1.19% | **−0.01σ** |
| **合计** | **+1.02σ** | **+0.07σ** | **−0.95σ** |

**归因必须按固定顺序逐项替换（PE → μ → σ），三项之和才能精确等于合计**——否则会出现交叉项，导致"每项都对、加起来不对"。可复算：

```
python3 scripts/calc.py erp --pe 13.52 --y10 1.634 --mu 5.68 --sd 1.19 --e 296.51 \
    --alt-pe 12.9 --alt-mu 5.05 --alt-sd 1.05
```

**一句话结论模板**：

> "ERP 已触及极端低估"这个判断，需要三个选择**同时取最宽松的组合**才成立；换成可复算的口径，它只是"回到中枢"。这不是谁对谁错，而是提醒——**当一个指标在临界点附近给出"是/否"判断时，先查口径，再动手。**

**推论**：凡报告引用卖方"ERP 已达 +1σ"，必须复算，并披露自己用的 PE 与窗口。**不复算就引用，等于把一个可调参数当成客观事实。**

## 四、通道 → 点位映射（买点坐标）

固定 10Y 与隐含 E，逐档反解：

```
目标 PE = 100 / (ERP_target + y10)      （ERP、y10 以百分点计）
对应点位 = E × 目标 PE
```

参考产出（E = 296.51、y10 = 1.634%、μ = 5.68、σ = 1.19）：

| 通道位置 | ERP | 隐含 PE | 点位 | 相对当前 | 操作含义 |
|---|---:|---:|---:|---:|---|
| +2σ | 8.06% | 10.32 | 3,059 | −23.7% | 极端低估，加到上限 |
| +1.5σ | 7.46% | 10.99 | 3,259 | −18.7% | 机构 ETF 流入高点 |
| **+1σ** | **6.87%** | **11.76** | **3,487** | **−13.0%** | **第一档买点** |
| 当前 | 5.76% | 13.52 | 4,008.87 | 0% | 未触发 |
| **μ** | **5.68%** | **13.67** | **4,054** | **+1.1%** | **≈ 公允价值** |
| −1σ | 4.49% | 16.33 | 4,842 | +20.8% | 偏贵 |
| −2σ | 3.30% | 20.27 | 6,010 | +49.9% | 极端高估 |

**三个必写的读法**：

1. **μ 那一行最重要**——它把"均值"翻译成"公允价值点位"。若 μ 对应点位与当前价只差 1%–2%，说明**当前就在公允位置，不是买点**。
2. **E 变动 → 整条曲线平移**：E 每变动 1%，所有档位点位同向移动 1%。买点是"随盈利增长的移动靶"，不是固定数字。
3. **通道宽度由 σ 决定**：σ 取 1.05 或 1.30，+1σ 买点会差 100 点以上（3,442 vs 3,545）。所以点位精度只能到"百点级"，不可当靶心。

## 五、历史校准

把 ERP 序列与滚动均值 ± 1σ/± 2σ 画在一起，标出突破上轨的时期。参考产出（A股 2007–2026）：

| 时期 | ERP | 通道位置 | 当时发生了什么 |
|---|---:|---|---|
| 2007-10 | −1.2% | 远低于下轨 | 牛市顶（PE≈50 倍） |
| 2011–2014 | 3.5%→8.0% | 连续突破 +1σ，2012–2014 破 +2σ | 长期熊市底，随后 2014–15 大牛 |
| 2015-06 | 1.5% | 回落下轨 | 杠杆牛顶 |
| 2018-12 | 6.5% | 短暂触及 +1σ | 贸易战底 |
| 2022-10 | 6.8% | 短暂触及 +1σ | 二次探底 |
| 2024-01~06 | 7.0%→7.5% | 突破 +1σ | 微盘股流动性危机 |

**两条必须写进报告的结论**：

1. **A股二十年里 +2σ 只在 2012–2014 被突破过。** 卖方常说"触及 +2σ 是极端低估"——用它当买点等于永远不买。**操作阈值应该用 +1σ。**
2. **本轮 ERP 极值往往不是"现在"**（如 2024-06 的 7.5%），若当前已回落，说明"性价比在变差"——这与"现在便宜得罕见"的市场叙事相反，值得单独点出。

## 六、三个陷阱

**陷阱一：低利率把 ERP 抬高了，但抬高的不是股票。**

必须先做"利率中性化"：把 y10 固定在若干年前的水平，看 ERP 还剩多少。示例：

```
实际 ERP 5.76%（y10=1.634%）
若 y10 回到 2.7%（2023 水平）→ ERP 仅 4.69% → 低于均值 5.68%，反而是"偏贵"
```

**校正方法**：同时看两个不含量价假设的指标——
- **股息率 − 国债**（如 +137~177bp）
- **ERP 的自身滚动分位**（如 53%），而不是绝对水平

只说"6% 的 ERP 很便宜"，等于把债券的牛市算成了股票的便宜。

**陷阱二：ERP 不能跨指数比绝对值。**

| 指数 | ERP | 自身历史分位 |
|---|---:|---:|
| 创业板指 | 2.08% | **95.0%** |
| 沪深300 | 5.76% | 84.7% |
| 中证500 | — | 69.0% |

创业板 ERP 不到沪深300 的一半，但自身分位反而更高——因为创业板历史 ERP 长期在 0 附近甚至为负。

**规则：只能纵向比（自己跟自己比），不能横向比（指数之间比绝对值）。**

**陷阱三：它是配置器，不是择时器。**

ERP 到 +1σ 后，市场完全可能继续跌到 +2σ。2024 年 1 月已破 +1σ，沪深300 到 2 月才见底。它回答"值不值得配"，不回答"下周涨不涨"。

## 七、落地：σ 分档 → 底仓

不做二元开关，做连续分档：

| ERP 的 σ 位置 | 底仓（占权益部分） | 对应点位（示例） |
|---|---:|---:|
| ≥ +1.5σ | 15% | ≤ 3,259 |
| +1σ ~ +1.5σ | 12% | 3,259–3,487 |
| 0 ~ +1σ（当前 +0.07σ） | **9%** | 3,487–4,054 |
| < μ | 6% | > 4,054 |
| 股息率 < 10Y 国债 | 0%（逻辑失效） | — |

**两条纪律**：

1. **底仓用机械规则，弹性仓用条件验证**——底仓的收益来自股息与均值回归，不依赖对盈利的判断。
2. **σ 分档必须与"股息率−国债"交叉验证**：若 ERP 显示便宜但股息率低于国债，说明便宜来自利率下行而非现金流，应下调一档。

## 八、报告中的呈现（必备四件套）

1. **序列图**：ERP 折线 + 滚动均值 + ±1σ/±2σ + 突破上轨的阴影区间。**不要只画一个当前值的刻度尺**——没有历史就没有说服力。
2. **窗口敏感性表**：至少两套窗口的 μ 与结论（§二）。
3. **口径归因表**：当 z 落在 1.0 附近时，必须给（§三）。
4. **点位映射表**：尤其要把 μ 那一行标出来（§四）。

## 附：数据可得性说明

完整周频 ERP 序列通常取不到。可行的替代方案：

| 方案 | 做法 | 代价 |
|---|---|---|
| 半年度序列 | 从券商研报的图表中取点（如中邮/iFind） | 采样稀疏，**会削平极值**，"突破上轨"次数被低估 |
| 极值点补插 | 额外加入已知历史极值（如 2007-10 −1.2%、2024-01 7.0%） | 混合精度，需在图注中披露 |
| 自算末点 | 用当日 PE 与 10Y 现算 | 与历史序列口径可能不一致 |

**必须披露的三句话**：① 序列是近似重建、非周频原始数据；② 半年度采样会削平极值；③ 因此图中"突破 +1σ"的次数是下限，不是全部。
